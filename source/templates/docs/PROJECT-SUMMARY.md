# 第五人格「朋友的酒」1.3.0 项目总结

日期：2026-10-09。项目提供持续人物 Q 弹缩放、换角色／时装后的模型重绑定、暂停停止恢复，以及游戏重启后的受限重连。用户已人工确认既有版全部求生者、监管者角色和时装，以及局内效果正常。当前代码写入范围为时装展示页与对局世界（匹配对局与训练场同属 `WorldBattle*` 世界族，走同一条已审核路径）。

## 本次更新

1.3 将固定文件哈希／导出地址准入改为动态导出解析、已审核原生实现指纹和逐能力脚本检查。资源、导出位置或源码行号变化可在实现检查通过后继续运行；代码或接口语义改变时停止对应能力，提供诊断和本地纯 JSON 适配包导入入口。

原生检查覆盖完整必要入口、明确跳转目标和所有可执行节。接入前检查唯一进程、路径、创建时间、磁盘与实际加载映像。脚本检查覆盖展示 8 项和训练 4 项实现，并在运行中及模型绑定前持续复核。缓存不会跳过现场检查，未知观察不会自动变为可信配置。

当前 NeoX Python 3.11 首次执行会设置函数 co_flags 的第 28 位。三个独立纯函数实验确认仅该执行状态位变化，因此内置已审核配置显式归一化这一位；其他标志和代码变化仍拒绝。该规则不自动扩展到未知引擎。

## 验证和交付

151 项单元检查、27 项原生 PE 模拟检查通过。本次 1.3 实际只读探针确认展示和训练均 SUPPORTED，主线程一致且模型 setter 调用为 0。训练场实际接入 5 个模型，连续尺度读回、暂停／恢复／停止和零残留检查通过。

实际中文空格路径解压即用、诊断运行通过，运行期数据只写在解压目录内，另一个运行实例保持 RUNNING。源码自包含重建和最终压缩包完整性检查另见验证记录。

1.3.0 起用户界面收敛为唯一的 `启动面板.cmd`，并且只保留「启动」「停止」「错误修复」三个按钮：状态、操作与诊断都在同一个面板窗口内完成，首屏不再需要在一堆脚本文件中翻找。发行物同时移除了安装器与卸载器，改为解压即用、直接删除目录即可移除。

成品为 Windows x64 程序包与完整源码包，附 SHA256SUMS.txt。用户无需开发工具；包内含官方 Python 3.14.0 和 .NET 8.0.30。旧 1.2 发行及原研究目录保留，本机已切换到 1.3 持续运行。
