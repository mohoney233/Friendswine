# 使用说明

## 这是什么

「朋友的酒」Q 弹模组，让《第五人格》里角色的身体与时装呈现 Q 弹缩放效果。

- 生效范围：**角色时装展示页** 和 **匹配对局**。
- 不修改游戏文件、不联网下载、不修改账号数据。

## 使用前提

- Windows 64 位系统。
- 游戏《第五人格》(dwrg.exe) 正在运行。
- 启动效果需要管理员权限（UAC 弹窗请点「是」）。

## 怎么用

1. 把压缩包**完整解压**到一个文件夹里（不要直接在压缩包里运行）。
2. 双击 **`启动面板.cmd`**。启动模组控制面板。
3. 先进入游戏（时装展示页或匹配对局都行），然后在面板里点 **「启动」**。
4. 第一次点会弹一次管理员权限提示，点「是」。
5. 面板顶部徽标变成「运行中」、底部「运行输出」出现 `"started": true`，就表示生效了。之后切换角色或时装会自动重新绑定。

面板有三个按钮：

| 按钮 | 作用 |
| --- | --- |
| 启动 | 启动效果 |
| 停止 | 停止效果并把模型恢复原状（**退出游戏前先点它**） |
| 错误修复 | 出问题时点它：先恢复干净、清掉上次会话的残留状态、清掉兼容缓存、再重新诊断一次 |

## 不想用了

模组是解压即用的，配置和数据都在解压出来的文件夹里，不写 C 盘用户目录，也不会改游戏文件。

- 想结束效果：在面板点「停止」，等面板显示已停止，再关闭游戏。
- 不再使用：直接把这个文件夹整个删掉即可，系统里不会留下任何东西。

## 常见问题

- **点「启动」后提示「未收到本轮游戏主线程回执」**：通常是还没进入可用场景，或游戏窗口被切到后台导致渲染变慢。请先进入时装展示页/训练场/对局，保持游戏窗口在前台，等几秒后再点一次。
- **面板右上角显示「普通权限」**：说明这个窗口不是管理员身份。点需要权限的按钮时，面板会先提示，并重新以管理员身份打开自己（只需确认一次）。
- **提示「当前没有运行中的模组」但效果确实还在**：说明效果是从**另一个文件夹**的面板启动的（状态按文件夹路径隔离）。请到当初启动效果的那个文件夹里打开面板点「停止」。建议固定只用一份。
- **游戏更新后想继续用**：直接点「启动」即可，它会自动做一次完整检查；如果不兼容会明确提示等待适配。
- **提示「前一会话存在未恢复模型的残留记录」**：说明上一次会话已经结束但留下了状态记录。点「错误修复」即可清理，之后就能重新启动；若仍失败请重启游戏。
- **不确定出了什么问题**：点「错误修复」，然后在面板底部的「运行输出」里看最后一行结论。
