## 1.3 训练场实际运行

新控制器实际识别 4 名求生者、1 名监管者，共 5 个模型。连续四次样本帧号为 2932、2962、2991、3054；同一目标 X 尺度依次约为 1.221、1.343、1.445、1.469，Y 对应变化，Z 为 1。尺度字段标为 immediate_setter_readback；证明写入后读回和持续变化，不单独证明每个渲染帧的最终画面。

暂停：restored=true，modified=0。恢复：RUNNING，modified=5。停止：STOPPED，restored=true，modified、unresolved、pending_restores 全部为 0。整个采样无 blocked 或恢复残留。最后样本回调耗时 p50 约 1.07 ms、p95 约 2.31 ms、max 约 7.31 ms，属于有限现场采样，不是通用性能保证。

验证后重新开启 1.3 自动重连与持续效果。原研究控制器已确认停止恢复，避免两套控制器叠加。新版本未通过强行重启游戏扩大验证；此前研究控制器实际跨游戏重启重连只作为既有行为证据。

安装器与卸载器已从本版移除，改为解压即用。真实冒烟确认：干净目录下运行后系统盘用户目录无新增文件，删除整个目录即可完全移除；含中文与空格的路径支持由单元测试覆盖。运行期数据写在解压目录内的 `data`，非本文件夹启动的会话按其自身路径隔离。另一台物理电脑尚未实测。

## 补充记录（2026-10-11）：对局判定、不可观测模型与残留清理

- **匹配对局实机采样**：在真实 `WorldBattle`（`is_battle_client` 未置位）中识别并绑定 5 个模型，`modified=5`，`skip_counts` 为空。此前对局判定用了「`is_battle_client` 为真或类名等于 `WorldBattleTrain`」，会把真实匹配排除在外；现改为按游戏自身的战斗世界族判定。这是单次实机采样，不是对所有模式、地图与角色形态的穷举验收。
- **不可观测模型**：对局中曾出现 `TARGET_ERROR`／`RESTORE_EXCEPTION`，原因均为 `NONPOSITIVE_OR_NONFINITE_SCALE`（模型仍报告有效但尺度不可读）。旧逻辑会把该目标锁成未恢复并阻止后续重新接入。现改为先请求已验证的官方重建，仍不可观测则退役并记录事件；新增 6 项单元测试覆盖「退役」「官方重建后恢复」「重建失败也退役」「可见但形状未知仍保留未恢复」四类分支。
- **清理残留状态**：新增 `cleanup` 动作（面板「错误修复」第二步调用）。真实冒烟确认它先归档再删除 `status.json`、`watch-control.json`、`watcher.json`，通道清空、证据保留；运行中的会话被拒绝清理。命令行与单元测试各覆盖一次。
- 单元检查合计 166 项通过。上述均为离线与本机现场证据，不构成未来版本或任意对局环境的保证。

## 限制

用户全部角色／时装及局内视觉验收属于既有版。本次 1.3 对展示执行了脚本只读检查，对训练执行了有限实际模型采样与恢复；未生成全部角色 ID 的穷举记录，未重新视觉验收所有角色。本机自动 UI 工具未能定位游戏窗口，未声称拍摄了新截图。

未来真实周更、不同引擎实现、所有特殊形态／附件不在本次验证结论内。匹配对局按同一条已审核路径开放，并已完成一次真实匹配实机采样（见上节），但未对所有模式、地图与角色形态逐项验收。根尺度可能被游戏其他逻辑读取，不宣称纯 GPU 隔离。未知原生实现不执行、未知关键脚本不写入、未确认恢复保留残留是本版实际边界；模型尺度不可观测时的退役同样不代表已确认恢复。
